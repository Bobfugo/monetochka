# Египетская монетка — со звуками и хаптиком (GitHub Pages)

Статическая мини-игра: анимированная 3D-монета «да/нет» с размытым фиолетовым фоном, **звуками** и **хаптиком**.

## Деплой на GitHub Pages
1) Залейте репозиторий.
2) В Settings → Pages:
   - Source: **Deploy from a branch**
   - Branch: **main** (или master)
   - Folder: **/webapp**
3) Откройте URL вида:
   `https://<username>.github.io/tg-coin-flip/`

## Запуск из Telegram
Сделайте у бота кнопку с обычной ссылкой на ваш Pages-URL.  
(Это не WebApp-кнопка, так что результат не отправляется боту — показывается внутри страницы.)

## Что добавлено
- Звук «whoosh» во время вращения.
- Звук «дзынь» при остановке (высокий для «ДА», чуть ниже для «НЕТ»).
- Хаптик: лёгкий удар при старте, мягкая вибрация во время спина, success/error при результате.
  - В Telegram-клиенте: `Telegram.WebApp.HapticFeedback`.
  - В браузере: fallback через `navigator.vibrate()`.

## Кастомизация
- Громкость: `SFX_MASTER` в `app.js`.
- Длительность/чувствительность хаптика — в функциях `haptic*` в `app.js`.
- Визуал монеты — SVG в `index.html`.
